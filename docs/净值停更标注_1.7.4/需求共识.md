## 我替用户定的细节（方案里会写清，用户可纠错）

- 标签文案：列表卡片显示「净值停更 N 天」；详情页净值旁显示「净值日期 2026-07-20 · 已停更 N 天，可能已清盘或暂停运作」
- 停更基金不打分：评分位置显示「净值停更」（与现有「数据不足」同一类处理），不参与同类排名，也不占同类样本数
- AI 投顾：筛选/排行类回答不再把停更基金列进候选；用户点名问某只停更基金时如实说明"净值自 X 日起未更新，可能已清盘"，不做推荐
- "数据不足"的基金目前在按收益排序时按 0 分排在中间，这次一并沉底（用户已选"和数据不足的一起"）
- 占位净值修复只改规则，不批量清洗历史数据；库里现有的两条占位值在读取时当作缺失，不需要手工改库
