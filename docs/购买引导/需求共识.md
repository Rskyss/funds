# 需求共识 · 购买引导（去哪里买）

日期：2026-09-03　状态：✅ 已对齐（三个关键问题用户已拍板）

## 原始需求（用户原话）

> 能否把购买的官方链接给找出来，因为用户看到想买，像去官网是否可以直接买，就是增加一个购买的引导

## 需求复述（产品语言）

用户在本站看中一只基金后，现在只能自己去别处搜代码。这次要在**基金详情抽屉的「交易规则」区块**加一个「去哪里买」小板块：告诉用户这只基金现在能不能买、去哪里买，并给出可以直接点过去的入口。

## 用户拍板（2026-09-03）

| 问题 | 拍板 |
|---|---|
| 点过去落在哪里 | **基金公司官网 + 天天基金都给**。场内 ETF 改为文字指引「券商账户搜代码买卖」 |
| 入口放哪 | **只放详情抽屉「交易规则」区块**；申购暂停/封闭期时按钮置灰并说明 |
| 措辞与合规 | 用**「去哪里买」**，不用「购买/立即买入」；旁边加一句免责声明「本站不销售基金，跳转后为第三方 / 基金公司平台」 |

## 已核实的事实（决定方案边界）

1. **天天基金**每只基金都有固定页面 `https://fund.eastmoney.com/<代码>.html`，页面上有「购买」「定投」按钮（直接的下单页 `trade.1234567.com.cn/FundtradePage/default2.aspx?fc=<代码>` 需要先登录，且带跟踪参数，不作为落地页）。
2. **基金公司官网做不到直达某只基金的购买页**（各家网址格式不统一），只能给到公司官网首页。东方财富的基金公司页（含「基本概况」子页）**不提供公司网址**，官网对照表要另外整理并逐家核实。
3. 本站 741 只基金（含份额）分属 **48 家基金公司**（今天用东财 F10 概况页「基金管理人」逐只解析，741/741 成功，0 失败）。前 12 家覆盖 490 只。库里目前**没有**基金公司字段，需要新增并回填。
4. 申购状态已在库里（开放 / 限购 N 元 / 暂停 / 场内交易 / 封闭），详情抽屉「交易规则」已展示，可直接复用来决定「能不能买」。

## 边界（不做什么）

- 不做列表卡片入口、不做 AI 投顾回答卡片入口（用户选了只放详情抽屉）
- 不接支付宝 / 微信 / 券商等其它渠道（网页无法可靠跳转到 App 内）
- 不做任何交易、不收集用户交易信息、不做联盟返佣
- 不改现有申购状态的抓取与展示逻辑

## 验收标准

1. 打开任一基金详情，「交易规则」下方出现「去哪里买」板块：一行状态说明 + 「天天基金」按钮 + 「XX基金官网」按钮 + 一行免责声明。
2. 开放 / 限购：两个按钮可点，新标签页打开对应页面；限购时状态行写明每日限额。
3. 暂停申购 / 封闭期：两个按钮置灰不可点，状态行说明「当前暂停申购 / 封闭期，暂不能买入」。
4. 场内 ETF：状态行写「场内基金，请在券商 App 输入代码 XXXXXX 买卖；以下链接仅供查看资料」，按钮可点。
5. 基金公司不在官网对照表里时：只显示「天天基金」按钮，官网位置显示「基金公司官网：请搜索「XX基金」」（不出现坏链接）。
6. 官网对照表 48 家全部人工核实可访问，且由用户过目一遍。
7. 点击按钮记一条匿名埋点（类型 `buy_click`，带基金代码和渠道），后台行为分析能看到「点击购买渠道」次数。
8. 单元测试覆盖：基金管理人解析、购买引导纯函数（五种状态 + 无对照表）、对照表文件格式；`npm test` 全绿。
9. 页面上不出现「购买 / 立即买入」等销售动作词（按钮文案为「天天基金」「XX基金官网」，标题「去哪里买」）。
