## 需要你留意的

1. **宝盈基金**：只有 http 可用（https 从本机和服务器都连不上）。按已批准的方案"只放 https"，页面上宝盈的 6 只基金只显示「天天基金」按钮 + 「请搜索「宝盈基金」官网」提示。如果你接受给 http 链接，说一声我就放开。
2. **摩根基金(中国)**：官网是 `cifm.com`（原上投摩根旧域名 51fund.com 跳转到此），不是摩根资管的全球站。
3. **平安基金**：`fund.pingan.com` 是平安集团域下的基金公司站，不是独立域名；公司自己的「联系我们」也以此为官网。
4. **浦银基金**（原浦银安盛）：域名仍是 `py-axa.com`，页面 title 已改为「浦银基金管理有限公司」。
5. **工银瑞信**：旧域名 icbccs.com.cn 已跳转到 `icbcubs.com.cn`，表里写的是新域名。
6. **国泰海通资管** `gthtzg.com`、**华泰证券资管** `htscamc.com`、**东方红资管** `dfham.com`：券商资管子公司，各自独立官网。
7. 大成 / 景顺长城 / 长城 / 银华 首页是跳转壳，表里写根地址，用户点过去会自动跳到真正首页。
